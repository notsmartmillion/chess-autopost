# Player portraits (optional)

Drop a photo here named after the player's surname in lowercase, e.g.:

    tal.jpg
    karpov.jpg
    fischer.png

The build step wires it up automatically when the name matches the PGN's
White/Black header. Portraits are rendered grayscale in a pale frame, matching
the channel style. If no file matches, a monogram card is shown instead — the
video always renders.
